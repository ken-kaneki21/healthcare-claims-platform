# Limitations

All records are generated for an independent portfolio project. The data model is illustrative. It carries no official CMS ACO REACH or HIPAA certification and has no employer deployment. The ML experiments are synthetic and cannot establish clinical efficacy. Local API integration testing provides no evidence of hardened public deployment. Cloud costs and live LLM behavior are unmeasured.

The OIDC verification uses an issuer-signature fixture. A real issuer and managed runtime still need deployment acceptance. The local monitor detects shifts in feature means and prediction percentiles. Outcomes and delayed-label performance require a separate evaluation. An approved live model is required to report provider accuracy, hallucination, token usage, or cost.
