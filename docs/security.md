# Local service security

Use the API on a local loopback binding. Demo tokens use a server-held HMAC secret with a maximum one-hour lifetime. Issue them through the local CLI and keep them out of logs and source files. There is no public token creation endpoint. Both finance and prediction routes bind data access to the signed tenant. Explicitly targeting another tenant returns 403. Extra body fields are rejected and queries bind SQL parameters.

The local identity mechanism has no revocation, external identity integration, or per-user roles. Authenticated requests are rate-limited per tenant within the API process with `CLAIMS_REQUESTS_PER_MINUTE`, default 120. A multi-instance deployment would need a shared limiter. Structured request logs contain request ID, HTTP method, status, and elapsed time. Prompt checks catch explicit cases covered by evaluation. Tenant isolation relies on the identity and database query filters. It does not depend on the prompt. The live provider adapter has a request timeout and does not receive ledger rows.
